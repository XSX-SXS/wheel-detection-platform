## 🎯 关键操作快捷键

| 快捷键 | 功能 | 使用场景 |
|--------|------|----------|
| `Ctrl + Enter` | 运行当前代码块 | 快速执行代码 |
| `Shift + Enter` | 运行并移动到下一块 | 连续运行实验 |
| `Alt + Enter` | 运行并插入新块 | 添加新代码 |
| `Ctrl + M` | 切换到命令模式 | 管理代码块 |
| `A` | 在当前块上方插入 | 添加代码 |
| `B` | 在当前块下方插入 | 添加代码 |
| `D + D` | 删除当前代码块 | 清理代码 |

## 🚨 重要提醒

1. **定期保存**：Colab会自动保存，但建议手动保存重要修改
2. **运行时限制**：免费版有使用时长限制，注意及时保存结果
3. **数据备份**：重要数据文件请本地备份
4. **网络连接**：确保网络稳定，避免运行时断开
5. **资源监控**：注意内存和CPU使用情况
